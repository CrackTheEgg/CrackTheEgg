# The Tape Pack

The Tape Pack is an Atlas application for exploring rave history through digital jigsaw puzzles, flyers, cassette recordings and vinyl archives.

## Application repository

[Open The Tape Pack repository](https://github.com/CrackTheEgg/TheTapePack)

The repository is private. Access requires permission from its owner.

Application code, its backlog and application development are maintained in that separate repository. This folder is an Atlas programme signpost and contains no copy of the application code.

## Future work

- Build a restoration pipeline using the OpenAI API as part of Tape Pack content engineering.
- Integrate [Record Hunter](../Record_Hunter/) as a record-finding tool. Record Hunter is currently on hold.

These are planned work items, not completed features.
