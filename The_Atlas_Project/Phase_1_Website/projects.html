In development · Python & Discogs

Discogs Purchase Integrator (DPI)

Discogs Purchase Integrator helps record collectors identify missing releases and assess purchasing options using their Discogs data.

The current prototype compares selected lists against a collection, checks candidate listings against buying criteria and groups suitable options by seller. The aim is to reduce manual research, avoid duplicate purchases and support more informed buying decisions.

A local web interface now supports collection and wantlist review. The next stage is to integrate purchase planning and prepare for AWS hosting.
